### SETTINGS
- Key binds
    - B: Open Backpack
    - Not Bound: Open Battle Logs
    - Not bound: New Waypoint
    - M: Open World Map
    - C: Open Summary
    - Not Bound: Save Hotbar Activator
    - Not Bound: Load Hotbar Activator
    - Not Bound: Start a battle with an angered pokemon
    - Not Bound: Refill Last Stack
    - X: Swap Tool/Change Hose Mode

- CobbleDollars
    - Overlay Position: Bottom Left
 
- Fight or Flight
    - fightorflight_visual_effect.json5: "move_indicator_x_relative": 0.8899999260902405
 
- Xaero's minimap: entity radar settings
    - add to "any" exclude list armadillo and painting
    - Display names: Player List
    - Display icons: Always
    - Entity icon scale: 1.20

- Radical Cobblemon trainers: rtcmod-server.toml
    - initialSeries = "freeroam"
    - freeroamRequiresCompletedSeries = false
 
- Resource Packs
    - Enable  "E19 - Cobblemon Minimap Icons"
    - Enable "Cobblemon Battle Tracks"
